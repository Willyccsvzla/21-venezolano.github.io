# Reversos de cartas

Estos tres reversos se derivan de las referencias visuales que compartió el usuario en `segments.zip`, `segments-2.zip` y `segments-3.zip`:

- `all-black.webp`: filigrana monocromática elevada sobre negro.
- `gold.webp`: filigrana dorada sobre negro.
- `silver.webp`: filigrana plateada sobre negro.

Se usan únicamente como reversos, así que no revelan el valor ni el palo de las cartas ocultas. La mesa aplica el diseño equipado por cada jugador a sus propias cartas ocultas.
